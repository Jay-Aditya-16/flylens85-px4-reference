# SkyDroid C10 Pro camera/gimbal

- **Sourced identity:** SkyDroid C10 Pro
- **Component class:** camera and gimbal payload

## Published source coverage

SkyDroid's support page names C10Pro in its RCSDK material. The same support page describes SkyDroid app-based gimbal control.

An official SkyDroid FPV player demo shows network playback and an example RTSP address, `rtsp://192.168.144.108:554/stream=0`.

## Provisional C10 Pro values

A secondary C10 Pro manual mirror reports the following values:

| Item | Provisional C10 Pro value |
|---|---|
| Input | 7.2–12 V DC |
| Current | 210 mA |
| Operating temperature | −10 to 60 °C |
| Mass | 61 g |
| Dimensions | 51 × 43.3 × 61.7 mm |
| Gimbal range | Pitch −90 to +10°; yaw/pointing −90 to +90°; roll 45° |
| Sensor/video | 2 MP effective; 1080p transmission; 2K recording; H.265 RTSP; H.264 recording |
| Storage | Stated up to 32 GB |

## Related official C10 values

SkyDroid's official S1PRO instruction PDF contains a table for **C10**, not C10 Pro. It lists 7.2-72 V input, 4 MP video hardware, similar mass/envelope values, and different storage guidance.
